TiConnect is a daemon that allows people under the same network to send messages, images and audio; have voice calls and allow for remote desktop access, all using LAN.

The most important aspect is that it must sit in the background as a daemon, allowing to receive messages even when the user didn't directly ran the application.

There are some constrains:

- Linux support, Windows isn't a priority now;
- X11 and Wayland support;
- Lightweight, as it will sit always active in the background;
- Ability to mute or ignore incoming messages;
